# Model Tuning History

These files document the model-development path before the final current pipeline. They are experimental tuning history, not the main current pipeline entry point.

## What This History Contains

- Stage 1 used `HalvingGridSearchCV` with `TimeSeriesSplit` to search Random Forest hyperparameters under time-aware validation.
- Stage 2/3 polished around stable Stage 1 choices using `GridSearchCV`.
- Stable choices penalized CV instability, so the selected settings balanced accuracy with robustness across folds.
- Final all-8-dataset evaluations generated MAE/RMSE/MAPE comparison tables.
- Alternative methods tested target transformation, regime switching, import/export decomposition, and export-weight tuning.
- The model-artifact creation script documents how trained artifacts were produced, but trained `.joblib` outputs are binary artifacts rather than source code.

## Artifact Policy

`.joblib` files are trained/model-parameter artifacts and are excluded from public GitHub. They can be regenerated by running the training and artifact-creation scripts in the correct project environment.
